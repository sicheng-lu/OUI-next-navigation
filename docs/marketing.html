04 - Why it works

Built different.On purpose.

Most observability is a billing model with a UI bolted on top. Three design choices we made differently.

A / Primitives

The primitive is the product.

Logs, metrics, traces, and agent spans are one table format with one schema. Joins are just joins.

- One storage. One engine. One bill.
B / Economics

Value scales with signal.

You pay for ingest and retention. Not seats, not hosts, not "indexed events". We don't punish curiosity.

- Predictable, line-item billing.
C / Contract

No feature gates without validation.

Every feature has a spec, a benchmark, and a public eval. We ship the eval with the feature.

- Published benchmarks, every release.
